# 自學教材系列・算術自習基礎練習

定題心算／算術工作紙產生器：題目可由隨機種子固定重現、附自檢答案頁，排版為 A4 多欄（每頁約 40–60 題，約需 3–5 分鐘）。對齊香港小學數學科**「數」範疇**之學習單位，方便家長與學生在家自習，亦供教師列印作課堂操練。

本專案**不設文字應用題**；幾何、度量、數據處理及代數方程亦不在現階段開發範疇之內。

**English (brief):** Seed-reproducible Hong Kong primary arithmetic worksheets (Number strand only). Pure frontend (HTML + ES modules). No word problems / geometry. Live: [https://wordbank-arith.pages.dev/](https://wordbank-arith.pages.dev/). Grade guide: [grades.html](./grades.html) · [https://wordbank-arith.pages.dev/grades.html](https://wordbank-arith.pages.dev/grades.html).

## 給用家

### 這是甚麼

「算術自習基礎練習」屬開源**自學教材系列**之一。線上選擇操練族與模式後，即可產生可列印之工作紙與答案頁；輸入相同隨機種子，可重現同一份卷，方便複習或分發固定版本。

- 工作紙產生器（Live）：https://wordbank-arith.pages.dev/
- 年級與課程對照說明：[`grades.html`](./grades.html)／https://wordbank-arith.pages.dev/grades.html

### 適合對象

- 香港小學學生（小一至小六「數」範疇基礎操練）
- 家長陪同自習、補課複習
- 教師列印作定題心算／堂課練習（非應用題卷）

### 如何使用

1. 開啟 Live 站或本機頁面，選擇**操練族**與**模式**
2. 設定題數、欄數及**隨機種子**（相同種子 → 相同題目）
3. 點擊「產生工作紙」
4. 點擊「列印／PDF」——工作紙為第一頁，答案頁為第二頁

建議列印設定：A4 縱向（直向）；「列印背景圖形」可按需要開啟或關閉。

### 範圍說明

| 涵蓋 | 不涵蓋（現階段） |
|------|------------------|
| 整數、分數、小數、百分數**互化**等「數」範疇計算操練 | 文字應用題、百分數應用（6N4） |
| 橫式心算、**直式得數練習**（只填最終得數） | 幾何、度量、數據處理、代數方程 |
| 可列印工作紙 + 自檢答案頁 | 多重嵌套括號、完整直式演算紙（寫出全部步驟） |

年級與教育局學習單位對照，請見 [`grades.html`](./grades.html)。詳細限制見下方「課程誠實說明」及 [`edb-primary-arithmetic-map.md`](./edb-primary-arithmetic-map.md)。

### 課程誠實說明（請勿誤標）

| 項目 | 本工具做法 |
|------|------------|
| 乘法表 | 預設為 **0–10**（對應 2N3）。另設「11–12 挑戰」模式，介面清楚標示為**課程外延展**，**並非**教育局規定必須掌握的 12×12。 |
| 10／18 以內加減 | 關卡一：10 以內；關卡二：18 以內（對應 1N2）。 |
| 退位減法 | 「100 以內」關卡嚴格劃分：1N4 為不退位，其後模式始涵蓋退位。 |
| 100 與 1000 | 拆分為**兩個獨立操練族**，題目絕不混雜在同一生成器內。 |
| 除法（表內） | 分兩模式：**整除（無餘數）**與**帶餘數（商⋯餘；必有餘數）**，介面標示清楚。 |
| 分數答案 | 答案一律化至**最簡**；若對照表另有規定，則接受最簡帶分數或假分數。 |
| 百分數 | 本工具僅做 **6N3 互化**（百分↔小數／分數）；**不做 6N4 應用題**。 |
| 直式得數練習 | 題面以直式呈現乘除結構，**只需填寫最終得數**；並非要求學生寫出完整直式演算步驟的演算紙。 |

## 給開發者

### 技術棧

- 純前端：HTML + ES modules（無建置步驟、無後端）
- 隨機種子可重現題目（`js/rng.js`）
- 列印／PDF 依瀏覽器列印功能
- 部署：Cloudflare Pages **Direct Upload**（非經 Git 自動建置）

### 本機靜態伺服器

必須透過本機 HTTP 伺服器開啟（直接以 `file://` 開啟可能無法載入 ES modules）：

```bash
cd wordbank-arith   # 或專案根目錄
python3 -m http.server 8765
```

瀏覽器開啟：http://127.0.0.1:8765/

### Smoke test（Node）

```bash
node js/smoke-test.mjs
```

### 目錄結構

```
wordbank-arith/
  index.html          # 控制列 + 可列印工作紙
  grades.html         # 操練族 → 年級／EDB 學習單位對照說明
  js/rng.js           # 支援重現結果的隨機種子生成器
  js/math-utils.js    # 因數、最簡分數、進位／退位判斷等數學工具函式
  js/generators.js    # 各操練族生成器（含直式得數練習與帶餘數）
  js/app.js           # 介面互動與排版邏輯
  js/smoke-test.mjs   # Node 煙霧測試
  edb-primary-arithmetic-map.md
  edb-primary-arithmetic-map.json
  sources/            # EDB PDF 原文及抽取文本
```

功能摘要：隨機種子重現題目；A4 多欄列印；自檢答案頁；香港教科書風格分數排版與**直式得數練習**（純 CSS）；零後端依賴。

### 已實作／延後

#### 已實作（橫式心算＋直式得數練習＋列印版答案頁）

1. 10／18 以內加減與數的分解（1N1、1N2）——分級設計
2. 乘法表 0–10 與表內除法（2N3、2N6）：**整除**與**帶餘數**分開模式（帶餘數題面「□⋯□」，第 1 題例題）；另設 11–12 **課程外延展**
3. **100 以內**加減法（1N4 無退位／進階退位）——獨立操練族
4. **1000 以內**三位數加減法（2N2、2N5）——**另一獨立操練族**，不與上述題型混雜
5. **直式得數練習**（3N2、3N3、4N1、4N2）——多位數×÷直式呈現、只填最終得數；除法可含餘數；另含**三數連乘／連除**
6. 因數／倍數／100 以內的質數／整除性判別（4N3、4N2）
7. H.C.F.／L.C.M.：兩數（4N4）；**三數標為進階課題**（非課標必修）
8. 同分母分數加減法（3N5、4N6）
9. 異分母分數加減法（5N2，分母 ≤ 12）
10. 分數乘除法（5N3、5N5 基礎題型）
11. 小數加減法（4N8）
12. 分數與小數互化（6N2）
13. 小數乘除（5N4、6N1）：10 的冪＋一般小數×÷＋**6N1.4 小數四則混合（≤4 個數）**
14. 四則混合計算連單層圓括號（3N4、4N5，不設嵌套括號）
15. **百分數互化**（**6N3**）：百分↔小數、百分↔最簡分數；**不含 6N4 應用題**

#### 延後處理

- **6N4** 百分數應用題（含百分變化）、文字應用題、多重嵌套括號
- 完整直式演算紙（要求寫出全部直式步驟）— 現階段僅提供**直式得數練習**

#### 品質保證（題目去重與低練習量題目過濾）

- **同頁題幹不重複**：生成 N 道題目時，均會以題幹（`prompt`）進行去重；如遇重複會重新抽取，並設有重試上限；僅在極端情況下適度放寬限制以湊足題數。
- **「包含零／恆等題」**（介面核取方塊，**預設為關閉**）：關閉時會過濾練習價值較低的題目，例如 `n − n`、`n + 0`／`0 + n`／`n − 0`、`n × 1`／`1 × n`、`n × 0`、`n ÷ 1`、`n × m ÷ m`，以及補數為 0 的分解題。若勾選此項，則可專門練習 0 的性質及恆等性（對應 1N2 等重點）。
- 預設排版導向：題目密度充足、具實質操練價值的心算頁面。
